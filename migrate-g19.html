Migrate Sapphire holders into g19

Seeds and delivers the same 56-token Sapphire-generation migration snapshot that g18 already carries, onto g19 instead. The site's own "Migrate previous iteration" button can't do this anymore — gno.land/r/nym-gemsnft000/g17 lived on the old Sapphire chain, which Pearl's RPC can't reach (separate chains, no shared state) — so this page works from the same 56-entry snapshot already committed to the repo, embedded below, and calls this collection's own AddMigrationSnapshotEntry / AdminDeliverMigrated directly.

Checking wallet…

1. Seed migration snapshot

Registers each of the 56 entries below into g19's own migration table via AddMigrationSnapshotEntry — one transaction, 56 messages (well under g19's own per-call limits). Owner-only; connected wallet must be the collection owner. Safe to re-run: each entry just overwrites its own key.

2. Deliver directly to holders

Mints each seeded entry straight to its original holder's wallet via AdminDeliverMigrated — owner-paid, no action needed from them. Only works on entries already seeded above (run step 1 first). Also safe to re-run: IsMigrationClaimed entries are skipped by the contract itself if called twice, though this page doesn't pre-filter — a repeat call for an already-delivered token will simply fail that one message.
